========================================
一、本文件夹内容说明
========================================
这是从 Flutter 工程里整理出来的【iOS 打包自包含工程】，
拷到你的 Mac 上即可直接编译 IPA，无需再从服务器拉取。

包含：
  ios/         —— iOS 原生工程（Runner.xcodeproj / Podfile / Info.plist 等）
  lib/         —— Dart 业务代码（与安卓 1.4.6+27 逐文件一致）
  assets/      —— 图标、图片、声音等资源
  config/      —— app_build.json（打包总配置）
  packages/    —— 本地插件 tencent_trtc_cloud（腾讯云 TRTC 音视频）
  pubspec.yaml / pubspec.lock  —— 依赖清单（与安卓同一份 lock）

========================================
二、在 Mac 上打包 IPA 的步骤
========================================
前置：Mac 已装 Xcode + CocoaPods + Flutter SDK

1. 把本文件夹整个拷到 Mac（路径别带中文和空格，比如放 ~/im-app-ios）

2. 进入目录，安装依赖：
   cd ~/im-app-ios
   flutter pub get

3. 进入 ios 目录，装 CocoaPods 依赖：
   cd ios
   pod install
   （若报权限/源错误，可先执行 pod repo update）

4. 打开工程（务必用 .xcworkspace，不是 .xcodeproj）：
   open Runner.xcworkspace

5. 在 Xcode 里配置签名：
   - 选中 Runner target → Signing & Capabilities
   - 勾选 "Automatically manage signing"
   - Team 选择你的 Apple 开发者账号
   - Bundle Identifier 保持 com.ioslgm.72322（勿改）
   - 确认 Capabilities 里有 Push Notifications（工程已带
     Runner.entitlements 的 aps-environment，正常会自动显示）

6. 选择真机或 "Any iOS Device (arm64)"，菜单 Product → Archive

7. Archive 完成后，在 Organizer 里点 "Distribute App"：
   - 上架 App Store → App Store Connect
   - 内测/越狱分发 → Ad Hoc / Enterprise
   然后导出 .ipa 文件即可。

========================================
三、注意事项（重要）
========================================
1. 【版本号】pubspec.yaml = 1.4.6+27，config/app_build.json =
   versionName 1.4.6 / versionCode 27，两边已一致。下次发版 +
   同步改这两处（versionCode 必须 +1）。

2. 【Bundle ID 一致】iOS 签名时，Apple 开发者后台的
   App ID / ad-hoc 描述文件必须也是 com.ioslgm.72322，
   错一个字母都签不上。

3. 【推送 = 极光推送（JPush）】
   - iOS 走极光（jpush_flutter 3.5.6），与安卓同一套代码；
     个推（getuiflut）只是服务端后台把 push_provider_ios
     配成 getui 时才会启用的备用通道，当前服务端未配置 → 不生效。
   - 当前 assets/config/app_config.json 的 jpushAppKey 是空的
     （""），极光 SDK 不会初始化，离线推送暂时收不到。
     在极光控制台拿到 AppKey 后填到该文件：
       "jpushAppKey": "你的极光AppKey"
     （iOS 和安卓用同一个 AppKey；极光后台该应用需上传
     iOS 推送证书 .p12 并绑定 Bundle ID com.ioslgm.72322）
   - Info.plist 已配好 remote-notification 后台模式、
     aps-environment entitlement；通知权限由极光 SDK 弹窗申请。
   - 桌面角标：打开 App / 未读归零会自动清零（PushService 处理）。

4. 【音视频】腾讯云 TRTC（packages/tencent_trtc_cloud）已包含，
   pod install 会一并装好。摄像头/麦克风权限已在 Info.plist 声明。
   后台通话引擎当前是 livekit（wss://www.hchat.top/livekit），
   livekit_client 2.13.0 与 flutter_webrtc 1.6.2 的 pod 版本已对齐。

5. 【ATS】Info.plist 已全局放行 http（NSAllowsArbitraryLoads=true），
   方便 ad-hoc 内测分发。上架 App Store 前建议按需收紧为仅 HTTPS。

6. 【图标/启动图】已按安卓最新 Hchat 品牌图重新生成完毕
   （AppIcon 15 张 + LaunchImage 3 张），无需在 Mac 上再跑
   flutter_launcher_icons / flutter_native_splash。
   以后换图标：替换 assets/icon/app_icon.png 与 splash_logo.png
   后，在 Mac 上执行 dart run flutter_launcher_icons 和
   dart run flutter_native_splash:create 即可。
